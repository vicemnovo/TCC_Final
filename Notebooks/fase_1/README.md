# Fase 1 — registro histórico

`fase1_vit.ipynb` é o notebook original de treinamento do detector ViT-Tiny + FFT, incorporado a partir da cópia fornecida pelo autor. A única alteração no notebook é a orientação inicial: o código e as saídas históricas foram preservados.

O notebook usa o dataset de faces do Kaggle e um subconjunto real do COCO, pede credenciais por Segredos do Colab e grava `phase1_best_model.pt` primeiro em `/content/`, depois em `/content/drive/MyDrive/TCC_Final/modelos/`. O checkpoint local correspondente está em `modelos/phase1_best_model.pt` e não é versionado. Não mova esse arquivo nem execute novamente a Fase 1 para continuar a Fase 3.4.

Este notebook é independente do fluxo de sincronização GitHub da Fase 3.4. Sua execução completa não foi repetida durante a organização do repositório; as métricas históricas não devem ser confundidas com a avaliação externa independente atual.
